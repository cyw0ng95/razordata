| REQ001203 | FIL/IO | **Zero-copy fixed file + buffer I/O — eliminate per-operation kernel↔user data copies.** After REQ001202 wires io_uring as the default backend, the ring uses generic fd-based `READ`/`WRITE` SQEs which still copy data through the kernel buffer cache on every operation. `IORING_OP_READ_FIXED` + `IORING_OP_WRITE_FIXED` with `IOSQE_FIXED_FILE` let the kernel access registered user-space pages directly (via mmu notifier), cutting per-operation copies by half. **Fix:** (1) Add `Ring.RegisterFixedFile(fd) → index` on `BlockDev.Open()`. (2) Add `Ring.RegisterBuffers(regions) → id` for registered page sets. (3) Replace `uring_sqe.PrepRead(fd, buf, off)` with `PrepReadFixed(index, buf, off)`. (4) Replace `uring_sqe.PrepWrite(fd, buf, off)` with `PrepWriteFixed(index, buf, off)`. (5) Add `BlockDev.SetReadBufRegion(addr, size)` / `SetWriteBufRegion(addr, size)` for dynamic buffer registration. (6) Validate with `TestFixedFileReadWrite` (Linux only) verifying that `fixed` reads produce identical results to non-fixed reads. | medium | small | REQ001202 | FIL/IO/uring_linux.go, FIL/DF/df.go |
| REQ001204 | FIL/IO | **Pre-registered file descriptor table for io_uring — eliminate per-operation fd lookup overhead.** After REQ001202, every `PrepRead()`/`PrepWrite()` passes a raw `int fd` that the kernel must resolve via the file descriptor table. `IORING_REGISTER_FILES` pre-registers an array of fds so SQEs reference them by index (one word) instead of full `struct file *` resolution. **Fix:** (1) Add `Ring.RegisterFiles(fds []int) → error` that calls `ioctl(fd, IORING_REGISTER_FILES, ...)`. (2) Add `Ring.UnregisterFiles()` on `Ring.Close()`. (3) `BlockDev` opens all data files at init and registers them in bulk. (4) `BlockDev` exposes `FixedFD(fileID) int` → index. (5) Update `SubmitBatch(count)` to use fixed fds by index. (6) Benchmarks: `BenchmarkFixedFDvsRawFD` — expect fd lookup overhead removed (~5-10% latency improvement on dense workloads). | low | small | REQ001202 | FIL/IO/uring_linux.go, FIL/DF/df.go |
| REQ001205 | FIL/IO | **REGISTER_BUFFERS batch I/O — single registration for all data pages, eliminating per-op buffer accounting.** After REQ001203, `READ_FIXED`/`WRITE_FIXED` require each buffer to be individually tracked by the kernel's `user_buf` accounting (kernel pins pages, tracks `mmu` notifiers). `IORING_REGISTER_BUFFERS` pre-registers a pool of `io_uring_buf` entries (addr, len, bgid) so the kernel can batch-track entire page sets with one registration instead of per-SQE accounting. **Fix:** (1) Add `Ring.RegisterBuffers(count int, buffers []io_uring_buf) → error` with `IORING_REGISTER_BUFFERS` ioctl. (4) `BlockDev.ReadAt()` picks a page from the buffer pool, passes `bufIndex` to `sqe`, uses the page as destination. (5) Add `TestBatchBufferRegistration` verifying that registered buffers produce identical results to per-op buffer allocation. | low | medium | REQ001203 | FIL/IO/uring_linux.go, FIL/DF/df.go |
