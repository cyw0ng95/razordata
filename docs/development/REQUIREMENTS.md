| REQ001303 | WAL/RP | **WAL checkpoint modes: passive, full, truncate, restart.** SQLite supports four checkpoint modes. Passive: copy as many frames as possible without blocking writers. (6) Surface via `PRAGMA wal_checkpoint(MODE)` query PRAGMA. (7) Add `TestWalCheckpoint_AllModes`.
