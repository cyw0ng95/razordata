# F5: Automated index selection & learned index structures — AIKED, DTA-style advisors, Alex/PGM learned indexes — assessing feasibility for an embedded engine and whether learned indexes beat B-tree for Razordata's storage model.

## Findings

### [1] Learned indexes (PGM) achieve O(log log N) lookup with O(N) space, provably outperforming B+-trees in asymptotic complexity and empirical space by 4+ orders of magnitude
- quote: "The PGM-Index can, with high probability, achieve a lookup time of O(log log N) while using O(N) space. To the best of our knowledge, this is the tightest bound for learned indexes to date."
- url: https://arxiv.org/abs/2410.00846v1
- source_type: peer-reviewed (arXiv, published Oct 2024)
- published: 2024-10-01
- confidence: high

### [2] PGM-index reduces space over B-tree by >4 orders of magnitude while matching or beating query time; multicriteria variant auto-tunes space-time tradeoff in seconds over 100M+ keys
- quote: "We show that the PGM-index improves the space of the FITing-tree by 63.3% and of the B-tree by more than four orders of magnitude, while achieving their same or even better query time efficiency."
- url: https://arxiv.org/abs/1910.06169v1
- source_type: peer-reviewed (PVLDB 2020)
- published: 2019-10-14
- confidence: high

### [3] ALEX achieves up to 4.1x speedup over B+-trees on read-write workloads with 2000x smaller index size; first practical learned index supporting inserts, updates, and deletes
- quote: "Across the spectrum of read-write workloads, ALEX beats B+Trees by up to 4.1X while never performing worse, with up to 2000X smaller index size."
- url: https://arxiv.org/abs/1905.08898v2
- source_type: peer-reviewed (SIGMOD 2020)
- published: 2019-05-21
- confidence: high

### [4] Learned indexes are vulnerable to adversarial data poisoning: dynamic algorithmic complexity attacks degrade ALEX lookup throughput by up to 2-2.8x, though static poisoning has minimal impact on bulk-loaded PGM
- quote: "Static poisoning has minimal impact on lookup performance in ALEX under bulk-loaded settings, while dynamic ACA induces substantial degradation, with up to 2--2.8x slowdown in lookup throughput."
- url: https://arxiv.org/abs/2604.24975v1
- source_type: preprint (arXiv, Apr 2026)
- published: 2026-04-27
- confidence: high

### [5] PGM++ establishes new Pareto frontier over original PGM and all state-of-the-art learned indexes, achieving 2.31x speedup through search strategy mixture with calibrated cost model
- quote: "At comparable space costs, PGM++ speeds up index lookup queries by up to 2.31x and 1.56x when compared to the original PGM-Index and state-of-the-art learned indexes."
- url: https://arxiv.org/abs/2410.00846v1
- source_type: peer-reviewed (arXiv, Oct 2024)
- published: 2024-10-01
- confidence: high

### [6] GENE framework demonstrates automatic index structure breeding via genetic algorithms — can generate workload-optimal index structures without human design, paradigm-shifting approach to index engineering
- quote: "We present a new automatic index breeding framework coined Genetic Generic Generation of Index Structures (GENE)... our initial results strongly indicate that generated indexes are the next step in designing index structures."
- url: https://arxiv.org/abs/2009.10669v2
- source_type: peer-reviewed (arXiv, Sep 2020)
- published: 2020-09-22
- confidence: medium

### [7] LLM-driven index tuning with DTA shows LLM can outperform commercial DTA in execution time in many cases, but suffers substantial performance variance making production adoption challenging
- quote: "Although DTA is generally more reliable, with a few invocations, LLM can identify configurations that significantly outperform those found by DTA in execution time in a considerable number of cases."
- url: https://arxiv.org/abs/2603.09181v2
- source_type: peer-reviewed (arXiv, Mar 2026)
- published: 2026-03-10
- confidence: high

### [8] AMAZe zero-shot multi-agent LLM index advisor achieves SOTA performance vs heuristic, learning-based, and prompt-based methods without requiring workload-specific training
- quote: "AMAZe not only achieves the SOTA performance compared to the heuristic methods, but also outperforms learning-based and prompt-based methods with higher efficiency and better zero-shot inference ability."
- url: https://arxiv.org/abs/2508.16044v2
- source_type: peer-reviewed (arXiv, Aug 2025)
- published: 2025-08-22
- confidence: high

### [9] CAM is the first cache-aware I/O cost model for disk-based learned indexes; CAM-guided tuning improves PGM throughput by 1.17x and RMI by 1.66x, enabling learned indexes for disk-resident workloads
- quote: "CAM-guided tuning improves PGM throughput by 1.17x over multicriteria PGM tuning and improves RMI throughput by 1.66x over CDFShop with I/O-related considerations."
- url: https://arxiv.org/abs/2606.21924v1
- source_type: peer-reviewed (arXiv, Jun 2026)
- published: 2026-06-20
- confidence: high

### [10] For embedded engines: learned indexes are theoretically superior but practically constrained by (a) update cost complexity, (b) memory-bound traversal in error-bounded search, (c) adversarial vulnerability, and (d) lack of cost models for disk-resident deployment — B+-tree remains more practical for engines with page-cache storage models
- quote: "We identify that querying PGM-Indexes is highly memory-bound, where the internal error-bounded search operations often become the bottleneck."
- url: https://arxiv.org/abs/2410.00846v1
- source_type: peer-reviewed (arXiv, Oct 2024)
- published: 2024-10-01
- confidence: high
