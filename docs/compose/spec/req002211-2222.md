**What was built** — REQ002211: `decomposeOp` now returns `(int, error)` and the `default` case emits a hard error for unknown operator types instead of silently wrapping via `decomposeNativeSource`. This change propagated through all 12 `decomposeXxx` helpers, `decomposePlan`, and `specializePlan` — every helper now surfaces operator-type errors up to `PipelineBuilder.Build`. REQ002222: a physical-DAG optimization framework mirroring `SQO/OC` — `Pass` interface (`pass.go`), `Optimizer` with `AddPass/Optimize/PassCount` (`optimizer.go`), and `Rewriter` with `Replace/Remove/Commit` (`rewriter.go`). The optimizer is wired into `PipelineBuilder` via an `optimizer *Optimizer` field and called in `specializePlan` after decomposition. The dead `hasBushyJoin` if/else in `decomposePlan` was removed (both arms identical after REQ002189/REQ002212).

**Journey log** — (1) RootHint sentinel bug in Rewriter: `rootHint int` defaults to 0, so `rootHint >= 0` is always true even when no root was claimed — added `hasRootHint bool` flag to disambiguate. (2) Removing `tryDecomposeFusedScan` pre-dispatch from `decomposeOp` broke `TestBitmapHeapScan_AndConditions` (BitmapHeapScan → FusedScanStageSpec fusion) — this was NOT pre-existing; the call must stay until REQ002225 ScanFusion pass provides a native BitmapHeapScan stage path. ## [S1] Problem

### REQ002211
`decomposeFallback` was already deleted (commit 91e3c955). The `default` case in `decomposeOp` (builder.go:456-459) still silently wraps unknown operator types via `decomposeNativeSource(op, st)`. The spec requires the `default` case to return an error (unknown operator type) — making `decomposeOp` a hard failure for any operator not explicitly listed in the type switch.

Additionally, `decomposeOp` currently returns only `int`. To surface an error from the default case, its return type must become `(int, error)` and all call sites must be updated.

### REQ002222
Physical-level optimization is scattered across bespoke functions in builder.go:
- `tryDecomposeFusedScan` / `tryDecomposeFusedIndexScan` (builder.go:1248/1415) — pattern-matching fusion pre-dispatch
- `hasBushyJoin` if/else in `decomposePlan` (builder.go:260-287) — dead logic, both arms identical after REQ002189
- `decomposeOp`'s ~40-case type switch interleaving lowering with optimization (builder.go:323-461)

There is no unified physical-level optimization framework. The logical-level `SQO/OC` already has `Pass` + `Optimizer` + `WalkOp` (optimizer.go); the physical layer should mirror it.

## [S2] Design

### REQ002211 — Error on unknown operator

**Return type change**: `decomposeOp` → `(int, error)`. The default case returns `(0, fmt.Errorf("px: unknown operator type %T", op))`.

**Call-site propagation**:
- `decomposePlan` calls `decomposeOp` — propagate error up
- `specializePlan` → `decomposePlan` — propagate error
- All intermediate `decomposeXxx` helpers that call `decomposeOp` propagate the error
- Each `decomposeXxx` signature becomes `func(...) (int, error)`

**Scope of change**: builder.go only. ~12 functions in the decomposition call chain need signature updates.

**Acceptance**:
- `decomposeOp` default case returns an error
- `go test ./internal/SQB/PX/... -count=1` passes
- SLT select1-select4 pass

### REQ002222 — Pass/Optimizer/Rewriter framework

Three new files in `internal/SQB/PX/`:

**pass.go** — `Pass` interface + `PassContext`:
```go
type Pass interface {
    Name() string
    Apply(ctx *PassContext, spec *PipelineSpec) error
}

type PassContext struct {
    Rewriter *Rewriter
}
```
`Pass.Apply` receives the `*PipelineSpec` and a context holding a `Rewriter`. The pass mutates the spec in place; error aborts the chain.

**optimizer.go** — `Optimizer`:
```go
type Optimizer struct {
    passes []Pass
}

func New() *Optimizer
func (o *Optimizer) AddPass(p Pass) *Optimizer
func (o *Optimizer) Optimize(spec *PipelineSpec) error
func (o *Optimizer) PassCount() int
```
`Optimize` runs passes in order, threading the `*PipelineSpec` through. With zero passes registered, it's a no-op.

**rewriter.go** — `Rewriter` (DAG mutation accumulator):
```go
type Rewriter struct {
    spec      *PipelineSpec
    replaces  map[int]StageSpec   // idx → replacement stage
    removes   map[int]struct{}    // idx → removed
}

func NewRewriter(spec *PipelineSpec) *Rewriter
func (r *Rewriter) Replace(idx int, newStage StageSpec, rootHint bool) error
func (r *Rewriter) Remove(idx int)
func (r *Rewriter) Commit() error
```
`Replace` records a replacement for a stage at `idx`; if `rootHint` is true the spec's `RootIdx` is updated. `Remove` records an index for deletion. `Commit` atomically rebuilds `Stages`, `Edges`, and `RootIdx` with a consistent index map.

**Integration** in `builder.go`:
1. Remove `hasBushyJoin` function and its if/else in `decomposePlan` — both arms identical. Collapse to one path.
2. **Deferred**: Removing the pre-dispatch `tryDecomposeFusedScan` call from `decomposeOp` is blocked — it is currently used by `BitmapHeapScan` → `FusedScanStageSpec` fusion (REQ002196). Removing it breaks `TestBitmapHeapScan_AndConditions`. The ScanFusion pass (REQ002225) must provide a native `BitmapHeapScan` → stage path before this pre-dispatch can be removed.
3. Add `optimizer *Optimizer` field to `PipelineBuilder`. `specializePlan` calls `b.optimizer.Optimize(spec)` after decomposition, before returning.

**Deviation**: T8 (removing `tryDecomposeFusedScan` pre-dispatch from `decomposeOp`) was blocked during implementation. The pre-dispatch call is currently used by `BitmapHeapScan` → `FusedScanStageSpec` fusion (REQ002196); removing it breaks `TestBitmapHeapScan_AndConditions`. The call remains in place and must be deferred to REQ002225 (ScanFusion pass) which will provide a native BitmapHeapScan → stage path.

**Acceptance**:
- `pass.go`, `optimizer.go`, `rewriter.go` exist with documented interfaces
- `hasBushyJoin` and its if/else in `decomposePlan` are deleted
- `Optimize` is called on every `*PipelineSpec` produced by `Build`
- `go build ./...` passes; `go test ./internal/... -count=1` passes
- Pre-commit gate (`./before-commit-cases.sh`) exits 0
